# SDK Generic Benchmark Matrix

The SDK generic matrix is generated by `aura-fixture-gen` so the benchmark inputs are not tied to grimoire names, row width, field count, or field order.

Generated fixture kinds:

- `sdk-tiny`
- `sdk-narrow`
- `sdk-wide`
- `sdk-reordered`
- `sdk-dense`
- `sdk-sparse`
- `sdk-edge-case`

For each generated fixture, metadata includes:

- schema name
- schema hash
- field names
- physical field types
- record width
- record count
- Aura0/Aura1/zstd paths, byte sizes, and SHA-256 values

The generated `sdk_bench_smoke.json` contains smoke benchmark entries for:

- `aura0-to-aura1-bytes`
- `aura0-to-aura1-bytes-verify`
- `zstd-aura1-to-aura1-bytes`

The smoke matrix is intentionally short enough to run in regular verification while still proving the benchmark harness accepts non-grimoire schemas.

The full closeout matrix is documented in `docs/research/sdk_full_generic_benchmark_matrix.md` and is produced by `aura_sdk_bench`.
